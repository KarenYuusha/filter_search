Category: Shot Skills
Tier: V
Required Level: Level 240

Source Details:
T5; Bow/Bowgun Only
MP Cost: 400
Buff Effect:
Upon use, you will gain 3 Quick Loader Charges. You can use this skill again but it won't overwrite this buff(you need to wait for buff to end in order to get this buff again). Bowgun Penalty: -1 Quick Loader Charge upon use.
When you use Cross Fire which is not fully charged yet, then you will automatically use 1 Quick Loader Charge for +1 CF Charge.
If you already learn Sneak Attack, then using this skill automatically gets you Sneak Attack buff based on Sneak Attack’s Level. However, its activated level cannot exceed this skill level. As usual, using this skill again, won't overwrite this sneak attack buff(you need to wait for buff to end in order to get this buff again)
Using Quick Loader again while Quick Loader buff is still active adds +5% * Skill Level motion speed to the next skill and recovers (MP Consumed by Quick Loader/2) MP.
This skill is max motion by default.
Buff Duration: (120 - 6 * Skill Level) seconds
Note: This skill's motion speed is always set to +50%.
Game Description: “Activates Cross Fire and increases its charge by 1 level if is not fully charged. This skill is not overwritten.”

SKILL: ELEMENT STARTER
==================================================

Category: Shot Skills
Tier: V
Required Level: Level 240

Source Details:
T5; Bow/Bowgun Only
Passive Effect:
Allows skills that aren't dual element to have [“Main Weap Ele” and “Arrow Ele”/"Katana Ele" (if Samurai Archery is Level 10)] as dual ele at same time instead of just Arrow Ele or Main Weap Ele(if don't have arrow ele). However, if skills that aren't dual element have fixed element, then fixed element will replace Arrow/Katana Ele, making it like [“Main Weap Ele” and “Fixed Ele”] as dual ele at same time. More info in ⁠💧elemental-guide🔥
Gain +1 stack everytime you deal a stronger element against the target. You can store up to 99 stacks. Its stack will be used for HP Recovery whenever you get attacked. HP Recovery = Floor(Skill Level * your MaxHP/1000) * stack
Game Description: “The element of bow or bowgun will be activated at the same time as the arrow. *Not valid for dual element skills. Gets a small recovery barrier each time you deal damage to targets with the element you are weak to.”

==================================================
SKILL: HUNTING BUDDY
==================================================

Category: Shot Skills
Tier: IV
Required Level: Level 150

Source Details:
T4; [Active] Bow/Bowgun Only
MP Cost: 100 summon; 0 cancel summon
Damage Type: Physical

Base Skill Multiplier:
1 + Total DEX/1000 + Stack Multi Bonus

Stack Multiplier Bonus:
0.1 * Skill Level * Stack

Maximum Stacks:
25

Stack Effect:

* Auto Attack Multiplier boosting skills such as Kairiki Ranshin and Berserk are added to the Base Skill Multiplier.
* Regislets such as Power Wave Modifier and Mana Thrash are also added to the Base Skill Multiplier.
* Hunting Buddy stacks do not have an icon.
* Stack damage calculation is handled without a visible stack indicator.
* Stacks reset to 0 every time Hunting Buddy attacks.

Base Skill Constant:
100

Attack Behavior:
Hunting Buddy attacks the target and returns to the user before attacking again.

Staying far away from the target or running away from it will therefore extend Hunting Buddy's attack interval.

Damage Modifier and Proration:

* Affected by Short Range Damage.
* Affected by Awaken Element.
* Not affected by Whack.
* Uses Physical Proration.
* Deals normal proration.

Stack Gain:
Hitting the target with a Shot Skill increases the effect that enhances Hunting Buddy's next attack.

With Twin Storm:
1 normal attack with Twin Storm (2 Twin Storm stacks) grants 1 Hunting Buddy stack.

Bow/Bowgun Bonus:
Unless the entire party is wiped out, Hunting Buddy will use First Aid before leaving the battle when the user is knocked out.

First Aid Level:
Hunting Buddy Skill Level

Game Description:
"Summons your companion to fight alongside you. It attacks every few seconds, causing normal attack proration. The effect that enhances your companion's next attack will stack when you hit the target with a Shot Skill; 1 normal attack with Twin Storm (2 Twin Storm stack) will gain you 1 Hunting Buddy stack."

SKILL: SPREAD SHOT
==================================================

Category: Shot Skills
Tier: V
Required Level: Level 240

Source Details:
T5; [Active] Bow/Bowgun Only
MP Cost: 200
Damage Type: Physical
Base Skill Multiplier (each Hit): 2 + 0.1 * Skill Level
Base Skill Constant (each Hit): 200
Ignore Defense: (30 + 5 * Skill Level)% (multiplied separately from "Armor Break" and "Physical Pierce")
Maximum Cast Range: 12m; AOE
Hit Count: 2 or 5 (depends on directional key usage upon cast)
-No Direction: Fan-shaped 5 Hits
-Front/Back: [Bow] 5 Hits wide arranged linear shots. [Bowgun] 5 Hits gatling linear shots.
-Left/Right: 1st Hit > your character performs [Evasion] 90° circling the target > 2nd Hit.
Ailment: None (with Neutral element); Ignite (with Fire element); Freeze (with Water element); Dazzled (with Wind element); Poison (with Earth element); Weaken (with Light element); Curse (with Dark element)
Ailment Chance: 1.2 * Skill Level% (when multiple hits are registered to the target, ailment chance adds up; so, it will be 100% when 5 hits are registered when using bow at skill level 9-10)
Ailment Resistance: 10 seconds
-Element Starter skill can make you deal 2 ailments when using different element bow/arrow; Element Talent regislets work and make you deal only ailment related to the regislet element.
This skill is not affected by short/long range damage; not affected by Long Range Skill; uses and deals physical proration.
Game Description: Attacks using 5 skillfully controlled arrows. Chance to inflict a status ailment (weapon element) on the target. Each hit on the same target slightly improves its performance. You can also change their direction the arrows are fired by using the directional keys.
Bow Bonus: The chance to inflict a status ailment is doubled. Additional hits from "Retrograde Shot" can occur up to 4 times.
Bowgun Bonus: The power is doubled (Base Skill Multiplier * 2) when activated using a directional key (left/right).
