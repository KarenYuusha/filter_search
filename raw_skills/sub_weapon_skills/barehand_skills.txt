SKILL: QI CHARGE
==================================================

Category: Barehand Skills
Tier: I
Required Level: None

Source Details:
(Active - self buffer)
Can be placed in combo
Cast time = 1 sec (affected by CSPD)
MP cost: [Floor(CurrentMP/100)]100
Effect:
- Flat Atk increase = Accumulated Qi * skill level^3 / 100. So at lv 10 = 1 Acc Qi = 10 Atk. Duration = 180 seconds
- Gain Qi based on this skill MP cost = MPBar + Floor(MPBar/3). So when u have 2k maxmp = you will gain 26 qi
[this skill MP cost is before combo tags such as after-save, cons and reflect. So, you can use it at ease with a combination of after-save, cons and reflect tags. But this skill MP cost is after Impact or any skill that can halves next skill MP cost. For example, when you have 2k maxmp and have impact buff, and you use this skill, then you will gain 13 qi and leave your MP like 1k left because you use Qi charge 1k mp cost. Well, that's kinda bad.]
- Stability Increase = 5% * skill level
Note: If you put this skill in save tags, it is always 0MP Cost and 0 qi gain regardless how much MP you have. So, don't put it with save tags at all.

Game Description:
Only usable when no Main or Sub-Weapon is equipped. Use up MP to accumulate Qi. ATK increases for 180 second based on Qi accumulated and Stability increases regardless of qi amount.

SKILL: LION RAGE
==================================================

Category: Barehand Skills
Tier: I
Required Level: None

Source Details:
(Active - self buffer)
Can be placed in combo
Cast time = 1 sec (affected by CSPD)
MP cost : 100
Effect:
- Using this skill will consume Qi to gain stack. Every 1 Qi Cost = 1 stack. Max at 10 Qi Cost or stack
- Critical rate increase = skill level * stack
- Normal attack constant damage increase = skill level * 5 x stack
- Normal attack multiplier increase = (skill level * 2 * stack)%
- Aspd decrease = 3000 - skill level * 150
- When you use other aura skills like Raving Storm/Internal Elixir, you will gain additional qi stack and also skip cast time, basically insta cast. If same aura = use Lion Rage, still same as normal(no gain qi and no insta cast time).
Here formula additional qi stack from lion rage
= 29 - floor(Lion_Rage_remaining_time){seconds is shown in below your hp bar}

Game Description:
Only usable if no Main or Sub-Weapon is equipped. Boost Normal Attack, Critical Rate with Qi for 30 second at cost of greatly lowered ASPD. Using another Qi based skill will end the effect.

SKILL: INTERNAL ELIXIR
==================================================

Category: Barehand Skills
Tier: I
Required Level: None

Source Details:
(Active - self buffer)
Can be placed in combo
Cast time = 1 sec (affected by CSPD)
Mp cost: 100
Effect:
- Using this skill will consume Qi to gain stack. Every 1 Qi Cost = 1 stack. Max at 10 Qi Cost or stack
- Buff Effect time = (10 * stack) seconds
- Reduce damage received by = (4.5 + 0.5 * skill level)% * stack
- Atk decrease% = (100 - 2.5 * skill level)%
- Hp recovery = 3% of max hp every 3 seconds
- If you got poisoned, then Hp recovery will get changed into Hp loss
Hp loss = 2% CurrentHp every 3 sec
- When you use other aura skills like Lion Rage/Raving Storm, you will gain additional qi stack and also skip cast time, basically insta cast. If same aura = use Internal Elixir, still same as normal(no gain qi and no insta cast time)
Here formula additional qi stack from Internal Elixir.
= floor(9.9 - Internal_Elixir_remaining_time / 10) {that remaining time seconds is shown in below your hp bar}
floor = round down

Game Description:
Only usable when no Main or Sub-Weapon is equipped. Use Qi to recover hp for a certain period of time and reduce damage received. Attack power goes down and damage from poison increases while it is in effect. Using another Qi based skill end the effect.

SKILL: EARTHSHAKER
==================================================

Category: Barehand Skills
Tier: III
Required Level: Level 250

Source Details:
(Active Skill, Yellow Aura)
T3; Main Barehand Only
Mp Cost: 100
Skill Effect:
Using this skill will switch between Earthshaker ON(Activate) & Earthshaker OFF(Deactivate). At the start, your Earthshaker is already in OFF mode.
During Earthshaker OFF mode
Passively gain +1 Earthshaker OFF stack every time gain +1 qi stack.
Fyi, can get from using Qi Charge to gain qi stack based on currentMP & gain qi stack from switching aura based on remaining time.
Using this skill during this OFF mode(not pair with Internal Elixir), will make you enter Earthshaker ON mode, and you gain qi stack by +(Earthshaker OFF stack). [Note: this might be a bug or feature. When activating this skill, then converting ES OFF Stack into gain qi stack will not affect ATK changes at all. The only way to fix this is to make changes to your accumulated qi stack aka. gain qi stack or consume qi stack, to make it back to normal.]
This OFF mode can pair/coexist with any aura(Lion Rage, Raving Storm, Internal Elixir). But keep that in mind.. Using this skill during off mode when you're in Internal Elixir mode, then nothing happened(no switch to Earthshaker ON mode at all) other than 100MP cost from Earthshaker alone.
During Earthshaker ON mode
Change your normal auto attack animation into 3 hits per cycle. Still +1 Auto Attack Multiplier. This auto attack from this skill, is not affected by Freeze ailment(the one that makes slow animation), but still gets affected by Motion Speed% normally.
Passively gain +1 Earthshaker ON stack every time consuming +1 qi stack.
Fyi, can get from switching/using aura that consumes 10~1 qi stack & using non-bh skills to consume qi.
Using this skill during this ON mode, will make you enter Earthshaker OFF mode, and recover your MP by +(Earthshaker ON stack * 10)MP. [i heard this mp recovery is inconsistent or buggy, but oh well]
This ON mode can pair/coexist with Lion Rage and Raving Storm, but not with Internal Elixir, since using Internal Elixir during this ON mode, it will force switch Earthshaker ON to OFF (still behaves like using Earthshaker normally aka. still recover your MP based on Earthshaker stacks when deactivating, but on top of that, after deactivating and entering ON mode, it gains Earthshaker stack due to gain qi stack from switching other aura to Internal Elixir happens in the end.)
DTE%(all ele including dmg to neutral) bonus = (2 * Skill lvl + Player Lvl/10)%
Stability% bonus = (Skill Level)%
Physical Pierce% bonus = (Skill Level * 2 + MAX[Skill Level - 5 ; 0])%
Physical/Magic barrier = (Earthshaker OFF stack * 2 * Skill Level + Player Lvl * Skill Level).
Note: This is same as Physical/Magic barrier from any sources such as equipment, food, etc. So it still block once every 30 seconds(without Barrier cooldown%) unless spam this skill(switch mode spam like unequip & equip phys/magic barrier) to reset this barrier block cd(this trick require you to have zero phys/magic barrier from gear/ava/etc. though)
Activating this skill(ON mode) will make your surrounding yellow aura if there is no aura in present e.g Raving Storm, Lion Rage; however if there is, then it will follow/strengthen their aura colour accordingly.

Game Description:
“Only usable when no Main or Sub-Weapon is equipped.
Get a barrier according to the qi accumulated by this skill. Increases all elemental advantages, physical pierce, and stability. The effect ends when Internal Elixir is used.”

xtalA is between Lion Rage & Internal Elixir

Raving Storm = xtalB + xtalC

Increase Base Guard Recharge by +(5 + 2 * Skill Level)
Increase Evasion count by +(2 + Skill Level * 0.4). [Note: decimal still exist even out'n in-battle for some reason, so there you go]
Increase Base Evasion Recharge by (0.1 * Skill Level). [New term to update later… At skill lv 10, then BH only Base Evasion Recharge (10s) is same as MD only Base Evasion Recharge (10s) btw]
Furthermore reduce Qi cost when use non-bh skills by Floor(0.5 * Skill Level)% qi cost.
So at level 10, this skill gives -5% Qi cost… so…. combine it with Ultima Qi Charge max lvl, then like this (20% Base - 10% Ultima - 5% H.Talent = 5% Qi Cost when use non-bh skills)

“If there are no slots, just hold them. Equips 3 crystas and get the ability of the 2 corresponding crystas when Lion Rage/Raving Storm/Internal Elixir activates.“
