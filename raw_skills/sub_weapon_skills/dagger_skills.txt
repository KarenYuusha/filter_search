- However if you proc both(Hidden Arm + Aggravate at same time), then you will get 6+6 add hits count => 7x(for some reason, when it is supposedly 6x tho??) AMPR multiplier.
- Hold on, it is not over yet… we have Amazing Throw which doubles dagger total hits count, so that means you can pair it with Hidden Arm + Aggravate, and you will get 12+6 add hits count => 9x AMPR multiplier. AMPR OVERKILL lmao
- And… lastly without Aggravate proc, so just Hidden Arm + Amazing Throw proc = 12 add hits => 6x AMPR multiplier..

SKILL: MAD DAGGER
==================================================

Category: Dagger Skills
Tier: IV
Required Level: Level 110

T5; [Active] Dagger Only
MP Cost: 200 MP
Damage Type: Physical
Maximum Cast Range: 16m
Main Attack:
Base Skill Multiplier: (0.5 + 0.15 * Skill Level + MIN[0.5; INT(Dagger WATK/10)/100]) * Hit Count
Base Skill Constant: 200
-If Main Weapon is OHS/Knuckles/Barehand, gets +0.5 Base Skill Multiplier bonus.
-Damage calculation is done once, then spread evenly between the hits in the same attack group.
-Main attack behavior: assigns dagger(s) to main target > assigns other dagger(s) to other mobs in battle within the range randomly > if there is dagger(s) left, repeat the same random order (this has strange behavior if the main target dies early).
-A knife which hit was guarded will be destroyed (Absolute Guard and Guard Break will not destroy knives). If the user got immobilized (Flinch/Tumble/Stun), all the knives will be destroyed.
-This attack is affected by short/long range damage; affected by long range skill; affected by Amazing Throw; uses and deals physical proration.
Follow-up Attack:
Base Skill Multiplier: MIN[Dagger WATK/(15 - INT(Base DEX/100)) + 50; 100]/100 * Hit Count
Base Skill Constant: 0
-If Main Weapon is OHS/Knuckles/Barehand, gets +0.5 Base Skill Multiplier bonus.
-Damage calculation is done once, then spread evenly between the hits.
-Targets only the main target.
-Maximum Attack Range: 7m.
-This attack is affected by short range damage; affected by long range skill; uses normal proration and deals no proration.
Game Description: Summons and controls a levitating dagger. Hurls the dagger at the target or a different target in combat to deal damage. After using the skill, the dagger follows you and delivers follow-up attacks in tandem with your normal attacks.
After Activating Mad Dagger, using Dagger Skills (excluding certain skills such as passives) will increase the number of levitating daggers. (Max 5)
The number of daggers decreases if you are immobilized (Flinch, Tumble, etc.) or if the enemy successfully performs Guard on daggers launched by the skill.
