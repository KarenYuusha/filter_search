SKILL: CLONING
==================================================

Category: Scroll Skills
Tier: Not explicitly specified in source
Required Level: Not explicitly specified in source

Source Details:
Active Skill (Buff)
MP Cost = 600
Action Range = Infinite
Base Cast Time = 3 sec
Base Clone Attack Multiplier = 1
Clone Attack Range = Default to your Weapon’s Auto Attack Range
Skill Effect:
When using this skill, it will summon Shadow Clone like Decoy. Surprisingly, they sync together. For example, if you use Cloning when there is a Decoy in your place, then that decoy will become Shadow Clone. If you use Decoy when there is a Shadow Clone, then that shadow will become Decoy.
Shadow Clone can follow the target, but cannot recover ampr via shadow auto attack.
Decoy cannot follow the target, but can recover ampr via decoy auto attack.
Switch between Cloning and Decoy, can refresh shadow clone/decoy duration. Also, they cannot inflict Neutral Proration as usual.
Duration of this skill is 60 seconds
Also, when using this skill, you will get base Max HP% penalty by (-75 + Ninjutsu Lvl x 5)%
If you use this skill again when there is a Shadow Clone in your place, then this skill will become Mortal Surrogate. Mortal Surrogate = Allow you teleport to where the shadow clone’s position instantly. After teleporting, you will recover 600MP plus you will become invincible for 1s after activate Mortal Surrogate, and that shadow clone will disappear.
NOTES:
If Distance between you and the shadow clone is over 12m away, then that shadow clone will stop attacking. But if you shukuchi to target, then that shadow clone 12m away from you, will follow the target where you shukuchi before automatically and attack them. However if their distance is over 20m, then that shadow clone will disappear
Srd/Lrd doesn't affect this skill damage
Combo tags affect this skill damage
